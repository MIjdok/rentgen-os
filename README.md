# РентгенОС · миссия «Шестерёнка»

Учебная «операционная система» в браузере. Школьник-стажёр делает сайт кружка робототехники в приложениях ОС и по ходу знакомится с IT-профессиями. Кейс хакатона «Цифровой код» 2026: «Профессии в IT: найди своё будущее».

## Запуск
Откройте `index.html` (копия — `rentgen-os.html`) двойным щелчком в Chrome / Edge. Сервер и установка не нужны. Шрифты подтягиваются из Google Fonts, без интернета работает системный шрифт. Прогресс хранится в `localStorage`; сброс: «Монитор → Сбросить миссию». `#fast` в адресе пропускает заставку.

## Начало
При первом запуске стажёр сам вводит имя и получает пропуск. Имя хранится отдельно от прогресса (`localStorage`, ключ `rentgen-os.player.v1`) и подставляется в чат и письма вместо `{{name}}`. Затем открывается «Почта» с вводным письмом Лизы: что будет на каждом из пяти этапов и как устроена система. Сменить имя можно в настройках. С `#fast` в адресе экран имени пропускается, используется имя по умолчанию.

## Что делает школьник (5 этапов)
1. **Разобраться в задаче** (Лиза, Аня): «Файлы» → таблица опроса, сортировка и фильтры, кнопка «В бриф» → бриф: главный читатель с объяснением, цель, приоритет.
2. **Собрать макет** (Дима): «Макет» → секции из библиотеки (в том числе живые: вопросы-раскрывашки, конструктор робота, счётчик дней), перестановка кнопками ▲▼ и перетаскиванием, свой заголовок и текст кнопки, робот, цвет, отмена/возврат. Приоритет из брифа должен стоять выше формы.
3. **Оживить страницу** (Кирилл): «Код» → найти и исправить ошибку в небольшом фрагменте, запустить, подсказки и «Вернуть рабочую».
4. **Проверить и исправить** (Таня, Сергей): «Проверки» → самому запускать 9 проверок (кнопка, узкий экран, пустая и заполненная форма, доступ к заявкам, живые секции; у счётчика дней по умолчанию дата в прошлом — её надо найти и исправить в коде), ожидаемое/фактическое; после правки проверка «устаревает».
5. **Передать результат** (Лиза): «Браузер» → готовый сайт, рентген (рамки поверх сайта, карточка элемента: что это, зачем, вклад специалистов, твои решения, код), кнопка «Открыть сайт» (страница открывается в новой вкладке браузера, на компьютер ничего не скачивается), карта направлений с объяснением по реальным действиям.

Чат — сопровождение: задача, подсказка, обратная связь. Работа идёт в приложениях. Единственный источник правды — три файла сайта (`index.html`, `style.css`, `app.js`); макет, код, предпросмотр (sandbox-iframe), проверки и экспорт работают с ними.

## Что ещё есть в ОС
- «Почта»: письма от команды и заказчика приходят по ходу этапов; заказчику можно ответить одним из вариантов.
- Плитки рабочего стола открывают то, что на них написано: «Бриф кружка» — PDF на 3 страницы, «Референсы» — галерея из 12 картинок с подборкой, «Шрифты» — архив с предпросмотром и распаковкой в «Файлы», «Репозиторий» — история коммитов, изменения файлов проекта и свой коммит.
- Достижения по профессиям: всплывают уведомлением и собираются на пропуске (клик по имени или аватару).
- Файлы и значки: выделение одним щелчком, открытие двойным (на телефоне — касанием), меню по правой кнопке, свойства.
- Окна прилипают к краям экрана; часы открывают календарь и историю уведомлений.

## Структура
- `index.html` — готовая сборка (всё внутри); `rentgen-os.html` — её копия; `ai-config.js` — ключ DeepSeek (подгружается отдельно, в сборку не входит).
- `src/shell.html` — разметка ОС с местами для вставки; `src/os.css`, `src/mission.css`, `src/apps.css` — стили.
- `src/os/*.js` — код ОС по порядку подключения: `00-base` (оболочка, окна, рабочий стол), `a-core`…`e-map-xray-glue` (приложения миссии), `f-player` (имя, пропуск, уведомления), `g-mail`, `h-viewers` (PDF, фото, архив, репозиторий), `i-achievements`, `j-assistant` (ИИ-помощник), `z-start` (запуск).
- `src/project.js` — движок проекта; `src/reply-provider.js` — реплики персонажей и клиент DeepSeek.
- `mission-content.json`, `mission-practice.json` — контент и сценарий, включая письма, достижения и материалы рабочего стола; `backup/` — оригиналы.
- `build.mjs` — сборка: `node build.mjs`.

## Проверки (нужны Chrome и `npm install`)
- `node tests/practice.mjs all` — сквозное прохождение (файлы на компьютере открываются двойным щелчком) от чистого старта до экспорта: A (1440, мышь) и B (390, касание), 78 + 76 проверок, включая открытие готового сайта в новой вкладке.
- `node tests/windows.mjs` — окна на 1280, 1024, 768, 1440: открытие, максимизация, восстановление, сжатие экрана.
- `node tests/audit-buttons.mjs` — клик по каждой кнопке приложений; `node tests/partner-check.mjs` — «печатает», скроллбары панелей, кнопка «Команда».
- `node tests/perf-xray.mjs` — нагрузка рентгена (CPU, перерисовки, мутации) в трёх состояниях.
- `node tests/shots2.mjs 1440 900 3` — скриншоты приложений.

## ИИ-помощник (DeepSeek)
В доке есть «Помощник» — робот Болтик. Он видит этап, задачи, бриф и красные проверки и подсказывает следующий шаг. С подключённым ключом через DeepSeek отвечают и Болтик, и персонажи в чате «Команда».

Куда вставить ключ (любой из двух способов):
1. Файл `ai-config.js` рядом с `index.html`: вписать ключ в кавычки `apiKey: "sk-…"`. Пересобирать не нужно, достаточно обновить страницу. Ключ будет работать у всех, кто открывает эту папку.
2. В самой ОС: «Настройки» → «ИИ-помощник и ключ DeepSeek». Ключ хранится только в этом браузере. Там же кнопка «Проверить связь».

Модель по умолчанию — `deepseek-flash` (быстрая), в настройках можно выбрать `deepseek-v4-pro`. Без ключа и без интернета всё работает: Болтик и команда отвечают заготовками из миссии, ошибки сети показываются понятным текстом.

Важно: ключ в `ai-config.js` виден любому, у кого есть эти файлы. Для показа на своём компьютере это нормально, для публикации в интернете — нет. В этом случае нужен небольшой сервер-прокси, который сам добавляет ключ; его адрес указывается в `baseUrl`. Прокси понадобится и в том случае, если браузер заблокирует прямой запрос к api.deepseek.com.

## Ограничения
- Проверялось в Chromium (Chrome) с эмуляцией касания; на реальном телефоне, в Firefox и Safari не проверялось.
- Данные опроса учебные (30 строк), не реальные.
- Ссылки «Куда идти дальше» ведут на внешние сайты; часть не открывалась из тестовой среды.
- Ответы ИИ зависят от DeepSeek: без ключа работают заготовки. Свой провайдер можно подключить так: `RentgenOS.setReplyProvider({ reply(req){ … } })`.
